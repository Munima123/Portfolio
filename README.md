# Munima Yasar Portfolio

This is a static portfolio website built with HTML, CSS, and JavaScript.

## Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Keep the repository public.
3. Upload all project files from this folder.
4. Open the repository on GitHub.
5. Go to `Settings` -> `Pages`.
6. In `Build and deployment`, choose:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main` or `master`
   - `Folder`: `/ (root)`
7. Click `Save`.
8. Wait 1 to 3 minutes.
9. Your website link will appear there.

## Recommended Repository Name

If your GitHub username is `Munima123`, use:

`munima123.github.io`

Then your website link will be:

`https://munima123.github.io/`

If you use any other repository name, the link will look like:

`https://munima123.github.io/repository-name/`
